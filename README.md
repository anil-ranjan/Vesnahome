# VesnaHome Static Property Website

A no-login property marketplace prototype built with plain HTML, CSS and JavaScript.

## Files
- `index.html` – page structure
- `styles.css` – responsive design
- `app.js` – demo data, filtering, details and form behavior

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Open **Settings > Pages**.
4. Choose **Deploy from a branch**, select `main` and `/root`, then save.

## Important
The current property submission form is a visual prototype and does not permanently store submissions. Replace the sample array in `app.js` or connect the form to a database/form service when needed. Photos use remote demonstration images; replace them with your property photos.
